# 安装与使用

## 安装

到仓库 Releases 下载 `Compositor-1.4.7-Chinese-arm64.zip`，解压后把 `Compositor 中文.app` 拖入“应用程序”文件夹，双击打开。

需要 Apple 芯片 Mac 和 macOS 26 或以上。Intel Mac 不在此发布包的支持范围内。

这是非官方本地构建，发布包仅本地签名，未经 Apple 公证；首次打开时 macOS 可能要求确认开发者来源。请核对下载是否来自本仓库的 Releases；可用同时发布的 SHA256SUMS.txt 核验压缩包。

## 使用

- 默认简体中文。“Compositor 中文 → 设置… → 通用 → 语言”可切换语言，重启后生效。
- “文件 → 打开项目…”可打开原有 `.comp` 工程。
- 按 ⌘F 搜索中文命令。例如“高斯”可找到“高斯模糊”。
- “设置… → 键盘快捷键”可调整快捷键。独立版的自定义设置与原版分开保存。

## 升级与卸载

中文版不自动安装官方更新。新版本需要重新适配，不能把 1.4.7 的补丁直接应用到其他版本。删除 `Compositor 中文.app` 即可停止使用；原版应用仍可使用。

## 常见问题

**它是汉化插件吗？**

这是基于源码编译的独立中文版。当前适配版本没有可加载汉化插件的接口。

**是否覆盖原来的应用？**

名称和应用标识不同，可与原版同时保留。工程文件默认打开方式没有被替换。

**工程还能在原版中使用吗？**

保存格式和混合模式等内部标识保持原样。中文版默认生成的图层、文件夹名称可能是中文，这些名称属于普通用户内容。

**所有英文都翻译了吗？**

主要界面已适配。型号、DPI、sRGB、像素单位、快捷键符号及用户内容保留原文；部分底层或系统提示可能仍是英文。
